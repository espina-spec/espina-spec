# Ana RC - Ejemplo ficticio

Este ejemplo no representa a una persona real. Sirve para probar la arquitectura Espina + CURRENT multisuperficie sin exponer datos privados.

Ana RC tiene tres mundos:

- `personal`
- `professional`
- `health`

El ejemplo muestra:

- `world_registry`;
- `surface_registry`;
- `current_contract`;
- `CURRENT_POINTER`;
- `CURRENT_STATE`;
- `CONTINUITY_STATUS`;
- un evento JSONL inicial.

El objetivo es que una superficie pueda leer la Espina minima, encontrar el CURRENT vigente, declarar continuidad y operar con limites.
