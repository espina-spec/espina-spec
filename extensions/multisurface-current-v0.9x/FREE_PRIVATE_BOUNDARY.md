# Free / Private Boundary

## Public extension material

The extension may include:

- schemas;
- synthetic examples;
- installable runtime tools;
- activation package templates;
- validators;
- sanitized proof reports;
- BYOK Drive connector documentation.

## Excluded private material

The extension must not include:

- OAuth client secrets;
- OAuth tokens;
- private signing keys;
- private memory backends;
- live personal Drive roots;
- private Aster RC Technologies implementation material;
- non-synthetic personal logs.

## Review note

The public branch can show the mechanism and evidence. Production credentials and private RC memory remain outside Git.
