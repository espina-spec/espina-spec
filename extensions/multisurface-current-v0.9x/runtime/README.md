# RC Runtime Installable

Paquete operativo para crear, activar y usar un RC de terceros sin depender de la memoria privada de Aster.

## Herramientas

```text
install_rc.py              Crea un RC local nuevo desde parametros minimos.
drive_current_generic.py   Lee/escribe CURRENT remoto usando activation package.
surface_cli.py             SDK/CLI minimo para superficies autorizadas.
validate_installable_runtime.py  Valida el paquete instalable y sus pruebas.
```

## Alcance libre

Este paquete contiene espina, activacion, CURRENT minimo, conectores genericos, permisos por superficie, export y revocacion.

## Fuera de alcance

No contiene claves OAuth, tokens, claves privadas, memoria privada de Aster ni politicas internas de Aster RC Technologies.
